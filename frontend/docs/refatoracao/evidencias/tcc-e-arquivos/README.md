# Evidências com dados fictícios

Capturas e `preview-checks.json` foram produzidos pelo script `frontend/scripts/preview-shell.cjs` em navegador isolado, com identidade e API fictícias. Não são dados de estudantes ou documentos reais. Os testes de download simulam indisponibilidade sem baixar arquivos para a máquina.

As evidências mostram o card verde na home, controle da lateral no rodapé, título/etapas/abas do TCC e pasta de documentos assinados em desktop e celular. A confirmação de arquivos reais e acesso no ambiente integrado depende da revisão manual da equipe.
